pAI privacy policy

Last updated: 2026-11-10

Who uses pAI

pAI is a private, non-commercial application used only by its owner and household. It is not offered to the public.

What data pAI accesses

With the user's consent, pAI requests read-only access to Google Calendar (calendar.readonly) and may later request read-only access to Gmail (gmail.readonly). pAI does not modify, send or delete anything in the user's Google account.

How the data is used

Data is used solely to give the owner personal overviews of upcoming events, such as daily and weekly summaries and scheduling conflicts. Limited excerpts may be sent to an AI language model provider to phrase those summaries. Data is not used for advertising, not sold, and not shared with anyone else.

Storage

Data is stored on the owner's private server and its private backups. Access tokens are stored on the same server and can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

pAI's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Revoking access stops all further data collection. Stored data is deleted on request by the owner.
